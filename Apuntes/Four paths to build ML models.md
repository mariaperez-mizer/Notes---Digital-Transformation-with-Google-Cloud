### BigQuery ML

BigQuery ML (SQL): Crear y ejecutar modelos de Machine Learning en BigQuery usando consultas SQL estándar. 
Abarco todo el proceso de la IA.

#### Beneficios

- Reduce la complejidad: Elimina la necesidad de gestionar herramientas independientes o cambiar de entorno.
- Acelera la producción: Se evita el paso de exportar y formatear conjuntos de datos masivos para marcos externos.
- Se integra con Gemini Enterprise Agent Platform: Fácilita el su uso para predicciones en línea en tiempo real.

### API preentrenadas

 API preentrenadas: Básicamente, utiliza modelos que Google ya ha creado y entrenado.

Modelos que Google ya ha entrenado para añadir rápidamente funciones inteligentes, como reconocimiento de imágenes o procesamiento del lenguaje, a sus aplicaciones.

- Se pueden implementar en una nube privada virtual, en las instalaciones del usuario o en la nube pública de Google.

API VIsion: Detectar automáticamente rostros, objetos, texto e incluso el sentimiento en las imágenes.

API Natural Language: Detecta la sintaxis, las entidades y el sentimiento en el texto, y lo clasifica en un conjunto predefinido de categorías. Puede determinar si los comentarios representan quejas, elogios, un intento de obtener más información sobre la empresa, etc.

Cloud Translation API

Speech-to-Text-API: convierte audio a texto para su procesamiento.

### Agent Studio en Gemini Enterprise Agent Platform (Desarrollo sencillo, sin código)

Agent Studio en Gemini Enterprise Agent Platform: Automatiza el entrenamiento y la optimización del modelo sin necesidad de escribir código. También te permite crear prototipos y personalizar modelos de Gemini o crear agentes de IA mediante una interfaz sencilla de apuntar y hacer clic.


Agent Studio incluye dos funciones principales:

- Creación y entrenamiento de modelos de machine learning mediante un panel visual, en lugar de escribir código.Una vez cargados los datos, el sistema compara automáticamente diferentes algoritmos y ajusta los parámetros para seleccionar el modelo óptimo.

- Personalización de modelos básicos: Se pueden adaptar a diversas tareas, como escribir, codificar o identificar imágenes.


- **Model discovery**: Acceda a un repositorio unificado, Model Garden,

- **Prompt prototyping and engineering** : Prototipado e ingeniería de indicaciones Utilice el espacio de trabajo visual para probar indicaciones, ajustar la configuración de creatividad y ver resultados multimodales interactivos al instante.

- **Model customization and tuning** Personalización y ajuste de modelos Adapte fácilmente los modelos base a las necesidades de su negocio ajustándolos de forma segura con sus datos propios.

- **Enterprise tools and grounding** Herramientas empresariales y validación
