1. Una pequeña empresa de comercio electrónico necesita alojar una API de microservicios en contenedores sin estado que experimenta picos de tráfico repentinos. Para lograr la máxima eficiencia de costos, la empresa requiere una solución que no genere costos cuando la aplicación esté completamente inactiva (facturación de pago por uso). ¿Qué producto sin servidor de Google Cloud es la solución ideal para esta carga de trabajo específica optimizada en costos?

   Cloud Run

2. Un equipo de ingeniería de datos ejecuta con frecuencia trabajos de procesamiento a gran escala y tolerantes a fallos que tardan varias horas en completarse. Estos trabajos no necesitan ejecutarse de inmediato y están diseñados para reiniciarse en caso de interrupción. ¿Qué modelo de precios de Compute Engine está diseñado específicamente para estas cargas de trabajo de procesamiento por lotes interrumpibles?

   Spot VMs

3. Una empresa minorista global almacena petabytes de datos históricos de ventas en Amazon S3 y Azure Storage. Para centralizar su análisis y evitar altos costos de transferencia de datos, necesita ejecutar consultas SQL de alto rendimiento directamente sobre los datos donde residen, sin migrarlos a Google Cloud. ¿Qué producto de Google Cloud resuelve este desafío específico de análisis en entornos multinube?

   BigQuery Omni

4. Una empresa manufacturera está considerando migrar su infraestructura local a la nube, pero le preocupa que el acceso a sus datos y aplicaciones no esté disponible cuando los necesite. Quieren asegurarse de que, si un centro de datos falla, otro esté disponible para evitar cualquier interrupción del servicio. ¿A qué se refiere esto?

   Reliability

5. Una empresa de medios global gestiona un conjunto complejo de microservicios de codificación de vídeo. Necesitan una plataforma que permita una personalización detallada de los tipos de máquinas, la configuración de nodos y las configuraciones de red para cada servicio, a la vez que ofrezca orquestación automatizada para la implementación y el escalado. ¿Qué servicio de Google Cloud está diseñado para ofrecer esta combinación de alto control operativo y orquestación gestionada de Kubernetes?

   Google kubernetes Engine (GKE)
