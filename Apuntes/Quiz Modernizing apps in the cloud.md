2. Una API de comercio electrónico exitosa está experimentando un rápido crecimiento, lo que podría sobrecargar sus sistemas de backend durante las temporadas altas de compras. La organización necesita implementar una medida de seguridad que limite la cantidad de solicitudes que un solo usuario o desarrollador puede realizar en un período de tiempo determinado para mantener la estabilidad del sistema. ¿Qué función de Apigee se utiliza para este propósito?
 
   API throttling
