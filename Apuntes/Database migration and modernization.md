Migración de plataforma mediante el método lift and shift. Las bases de datos se migran desde entornos locales y de nube privada a una base de datos del mismo tipo alojada por un proveedor de nube pública, como Google Cloud.

---

### Productos de Google

El Servicio de Migración de Bases de Datos (DMS) de Google Cloud puede migrar fácilmente sus bases de datos a Google Cloud, o bien, Datastream puede utilizarse para sincronizar datos entre bases de datos, sistemas de almacenamiento y aplicaciones.

Google Kubernetes Engine (GKE): máquinas virtuales
Compute Engine para alojar los servicios
Pub/Sub y Dataflow para enviar datos operativos a su repositorio analítico en BigQuery.
