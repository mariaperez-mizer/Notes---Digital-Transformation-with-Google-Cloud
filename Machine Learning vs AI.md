
### AI
Amplio campo de la informática dedicado a la creación de sistemas que pueden simular la inteligencia humana para realizar tareas. Estas tareas incluyen el aprendizaje, el razonamiento, la resolución de problemas y la toma de decisiones.


---
### Machine learning

Es un subconjunto de la IA que permite que una máquina aprenda de los datos sin ser programada explícitamente. Se basa en diversos modelos para analizar grandes cantidades de datos, extraer conclusiones y, posteriormente, realizar predicciones y tomar decisiones informadas.

- Mejoran el rendimiento con el tiempo a medida que se entrena o se expone a más datos.
- Cuanto más datos se utilizan, mejor es el modelo.
- Algoritmo para construir IA.
- Computer vision, sistemas expertos y el procesamiento del lenguaje natural.

Problemas que resuelve:
- Reemplazar o simplificar los sistemas basados ​​en reglas.
- Automatización de procesos. Está diseñado para realizar predicciones y tomar decisiones repetitivas a gran escala.
- Procesar el lenguaje natural e identificar el sentimiento del cliente y el tema de cada mensaje.

>[!important] Los datos se consideran de baja calidad si no se ajustan al problema o presentan algún sesgo.

### Calidad de los datos

- **Completeness** Integridad : Se refiere a si toda la información necesaria está presente.
- **Uniqueness** Los datos deben ser únicos. Los registros duplicados lo confundirán y no podrá identificar patrones correctamente.
- **Timeliness** La actualidad de los datos se refiere a si estos están actualizados y reflejan el estado actual del fenómeno que se está modelando.
- **Validity** La validez implica que los datos se ajustan a un conjunto de estándares y definiciones predefinidas, como el tipo y el formato.
- **Accuracy** La exactitud refleja la veracidad de los datos.
- **Consistency** La consistencia de los datos se refiere a si estos son uniformes y no contienen información contradictoria.

### Generative AI

Se trata de un tipo de IA capaz de producir contenido nuevo, incluyendo texto, imágenes, audio y datos sintéticos.
- Bots conversacionales
- Generación de contenido
- Síntesis de documentos
- Descubrimiento de productos

IA tradicional analiza datos existentes vs IA generativa se centra en crear algo nuevo: un primer borrador de un correo electrónico, una imagen a partir de una descripción o un resumen de un documento extenso.

>[!Important] La IA generativa es la creadora, la IA con capacidad de acción es la que ejecuta. No solo crea el contenido; también puede actuar sobre él.
