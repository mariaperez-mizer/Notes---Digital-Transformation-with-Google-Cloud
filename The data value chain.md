

Procesamiento de datos

1. Data genesis: creación inicial de una unidad de datos.

2. Data collection: incorporación de la unidad inicial, mediante la transferencia.

3. Data processing: El procesamiento de datos ocurre cuando los datos sim procesar recopilados se transforman  en un formato listo para obtener información.

4. Data storage: Es donde los datos llegan, pueden encontrarse y están listos para el análisis y las acciones. 
	-  NoSQL: Operaciones rápidas de lectura y escritura.
	- Data waregousing: para un acceso rápido al análisis.
	- Object storage: para los datos no estructurados.
	
5. Data analysis: Proporciona orientación sobre la acción empresarial(las entradas de la fase de Data processing se montan para crear el producto final). 

6. Data activation: 
	- Decisiones automatizadas
	- Paneles de inteligencia empresarial (BI dashboards)
