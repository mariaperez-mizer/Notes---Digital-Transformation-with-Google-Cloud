### Productos de Google
1. Cloud SQL ofrece bases de datos relacionales totalmente administradas, incluyendo MySQL, PostgreSQL y SQL Server como servicio.

   **Beneficios**
   - No requiere instalación ni mantenimiento de software.
   - Admite copias de seguridad gestionadas
   - Encripta los datos de los clientes cuando se encuentran en las redes internas de Google y cuando se almacenan en tablas de bases de datos, archivos temporales y copias de seguridad.
   - Firewall de red que controla el acceso a la red de cada instancia de base de datos.

Es un servicio de bases de datos relacionales totalmente gestionado para MySQL, PostgreSQL y SQL Server.
El Servicio de Migración de Bases de Datos (DMS) facilita la migración de sus bases de datos de producción a Cloud SQL con un tiempo de inactividad mínimo.


2. Spanner es un servicio de base de datos relacional totalmente gestionado y de misión crítica que se escala horizontalmente para gestionar picos de actividad inesperados.

Una base de datos relacional totalmente administrada con escalabilidad ilimitada, consistencia robusta.
Esta base de datos en la nube distribuida globalmente y compatible con ACID gestiona automáticamente las réplicas, el particionamiento y el procesamiento de transacciones, lo que permite escalar rápidamente para satisfacer cualquier patrón de uso y garantizar el éxito de los productos.

3. BigQuery es un almacén de datos totalmente administrado.se encarga de la infraestructura subyacente, para que los usuarios puedan centrarse en:
    -  Utilizar consultas SQL 
    Ofrece dor servicios:
    - Almacenamiento(petabytes)
    - Análisis (machine learning, business intelligence y análisis geoespacial)
- Los datos se cifran en reposo de forma predeterminada,se utiliza para proteger los datos almacenados en un disco, incluidas las unidades de estado sólido, o en medios de copia de seguridad.
