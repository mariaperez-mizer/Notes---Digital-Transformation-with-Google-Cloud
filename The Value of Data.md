##### Tipos de datos

- Estructurados
	- Organizados y definidos.
	- Almacenados en tablas con relaciones entre diferentes filas y columnas.
	- Por ejemplo: Hoja de cálculo o DB.
	
- Semi-estructurados
	- Organizados de manera jerárquica, pero sin una diferenciación completa 
	- Sin un orden en particular.
	- Correos electrónicos y archivos en formato HTML, JSON y XML.
	- No tiene una estructura formal , pero si contiene etiquetas para que sea mas fácil de analizar.
	
- No estructurados
	- No tiene modelo de datos predefinido 
	- No está organizada.
	- Las categorías incluyen:
		- Texto; documentos, presentaciones o redes sociales.
		- Archivos de datos como imágenes, audios y videos.
		- La actividad de infraestructura y los datos de rendimiento; archivos de registro de servidores, redes  y aplicaciones o datos de salida de sensores de internet de las cosas (IoT).
