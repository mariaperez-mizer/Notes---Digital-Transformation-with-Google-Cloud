1. Una plataforma global de comercio electrónico experimenta un aumento repentino del 10 000 % en el tráfico. El sistema aprovisiona automáticamente nuevos recursos para gestionar este incremento de forma eficiente sin intervención manual. ¿Qué término de operaciones en la nube describe mejor esta capacidad de optimizar las operaciones para el crecimiento?

   Operational excellence

2. Un equipo de SRE observa que sus servidores de bases de datos están funcionando al 98 % de su capacidad de CPU. Los servidores no pueden gestionar más trabajo sin ralentizarse. ¿Qué métrica utiliza el equipo para controlar la proximidad del sistema a su límite?

   Saturation

3. Una empresa aloja una base de datos crítica en un único servidor ubicado en una sola zona. El director de tecnología (CTO) teme que un incidente localizado, como un corte de energía o un incendio en ese centro de datos específico, pueda dejar todo el sistema fuera de servicio. ¿Qué estrategia de diseño debería implementar el equipo para garantizar que el sistema permanezca operativo y accesible durante tal fallo?

   Replicar la base de datos y los recursos en varias zonas dentro de la región.

4. Los usuarios de una empresa de software de vídeo han informado de que subir vídeos 4K a su producto está tardando más de lo habitual. El equipo de ingeniería necesita rastrear la latencia de las solicitudes para determinar la causa del retraso. ¿Qué herramienta de Google Cloud Observability deberían utilizar?

   Cloud Trace

5. Tu equipo de ingeniería se ha fijado un objetivo interno estricto: mantener la latencia del sitio web por debajo de 300 milisegundos para el 99,9 % de las solicitudes durante el próximo mes. Si no se alcanza este objetivo, el equipo se compromete a detener el desarrollo de nuevas funciones para centrarse en la estabilidad. ¿Qué concepto de ingeniería de confiabilidad de sitios (SRE) representa este objetivo interno?

   Service Level Objective (SLO)
