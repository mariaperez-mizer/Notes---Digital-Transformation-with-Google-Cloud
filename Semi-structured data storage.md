### Productos de Google 

1. Firestore es una base de datos en la nube NoSQL flexible y escalable horizontalmente para almacenar y sincronizar datos en tiempo real.  
    -  Se puede acceder mendiante apps móviles o web.
    - Almacena datos en forma de documentos, que se guardan en colecciones.
    - Automatic scaling.
    - Uso sin conexión a través de una base de datos completa en los dispositivos de los usuarios.
2. Bigtable, el servicio de base de datos NoSQL de Google para big data (Analytics, Maps, Gmail).
    - Grandes cargas de trabajo con baja latencia constante, es decir, responde a solicitudes rapidamente.
    - Ofrece un alto rendimiento, lo que significa que puede enviar y recibir grandes cantidades de datos.
    - Es excelente opción para Iof, análisis de usuarios y análisis de datos financieros.
